## Planning Workflow

This workflow guides the process of implementing planned features from the project's design documentation.

### Steps

1. Check the `/Users/user/Projects/BookBoss/Design/` directory to locate the relevant documents containing planned features (e.g., UI updates, new backend functionalities).
2. Read the document to identify the next major feature slated for implementation.
3. Design a comprehensive `implementation_plan.md` that outlines the necessary frontend UI changes, backend API additions, database schema updates, and test plans.
4. Pause and notify the user to review and approve the implementation plan.
5. Following approval, break down the execution into a `task.md` checklist and begin developing the feature incrementally.
6. After completion, log the major changes in `Design/needs_review.md` as per the core user rules.
